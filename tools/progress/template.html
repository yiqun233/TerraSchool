资料与环境核验

“需核验”表示现有证据仍不足以关闭相关验收，不表示资料完全不存在。先查仓库和参考资料；仅对实际缺失部分补充。

每完成一部分，就更新同一套事实

1. 先确定 F 模块、REQ/SUP 细项和 REV 任务。新增范围先在功能清单分配稳定 REQ 编号。

2. 修改“功能细项追踪”的开发、验证、验收三列，说明已做范围、剩余工作，附实际证据。局部通过继续保留未完成部分。

3. 有歧义就登记 Q 问题，写清影响和等待时可继续的工作；资料不足关联 DATA。已确认的问题保留结论、来源与日期。

4. 更新受影响 F 汇总和 REV 状态，运行下列命令生成并校验本页面。

python -X utf8 tools/progress/build.py
python -X utf8 tools/progress/build.py --check

页面是生成的只读视图，不使用浏览器本地存储保存进度；每次更新回到仓库文档，便于你和 AI 共同维护、比较差异。

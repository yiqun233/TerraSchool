## 1. 从哪里看

直接用浏览器打开同目录的 `开发总览.html`。页面包含全部数据和样式，无需启动后端、数据库或联网，支持模块展开、关键词搜索、P0～P3/支撑/未来范围筛选、开发状态筛选、待确认/资料/待验收筛选。问题页可按领域、档位、状态检索并按档位排序，顶部矩阵显示未确认问题在领域 × 档位上的分布，点格子即筛选；关联 S 档问题的细项在功能全景里单独标出。路线显示验收关口与 REV 任务。

点击总览中的文档或验证记录链接，默认进入内置阅读器，正常显示标题、表格、列表、引用和代码块。左侧章节目录可以定位，文档内的 Markdown 链接继续在阅读器中打开，支持浏览器前进/后退、刷新和带章节的链接；“返回开发总览”回到原总览视图。只有明确点击“查看 Markdown 源文”才直接打开原始文件。原始 Markdown 仍是唯一维护依据，不在阅读器另存修改。

阅读器在生成时嵌入 `doc` 下全部 Markdown 和根 README/AGENT；后续文档更新后需重新生成，避免阅读旧快照。原文 HTML 不执行，Mermaid 等围栏保留可读代码，不引入在线渲染脚本。

默认从八个领域进入 43 个 F 模块，再展开具体能力。REQ 是范围清单中的稳定能力编号，SUP 是工程交付支撑，AI 是未来保留能力。现有功能全集仍不是旧菜单、合同与手册的全部逐项核验结果；未映射来源继续按 DATA-02 跟踪。

“局部实现”必须同时看已有范围和剩余工作。“已实现”说明该细项有代码；“已验证”必须有对应范围的证据；“已验收”必须记录确认人、日期、案例与结论。自动测试和文档整理不替代业务验收。页面数量只帮助定位工作量，不是完成百分比。

HTML 是生成的只读视图，不直接手改，不使用浏览器本地存储维护第二套进度，也不在页面点击“完成”后假装已同步仓库。

## 3. 每批工作结束的回填顺序

1. 确认本批对应的 F、REQ/SUP 和 REV。新增功能先在范围清单分配稳定 REQ ID，禁止排序后重编号；新增工程支撑在细项台账分配 SUP ID。
2. 回填本批设计和实际验证记录，细项表更新已有范围、开发状态、验证状态、证据链接、剩余缺口。只完成一部分就保留局部实现；不要把整条需求随一个按钮一起关闭。
3. 发现规则歧义立即追加 Q，说明现状、影响、等待角色和下一步，并按既定枚举填写领域、类型、重要度、紧急度。将新 Q 加入同文件状态索引，未回复保持待确认；部分确认写清已确认和未确认范围。资料证据不足关联 DATA，具体缺哪一部分写在细项/问题正文。
4. 更新受影响 F 汇总和 REV 状态；已完成防护但远程/真实样本未验时写“本机已验证，专项未完成”，不要退回“未开发”，也不能写整项完成。
5. 有正式验收结论再填写已验收及证据。某部分因问题停留时，无关子项可继续，问题保留到结论和实现都落实。
6. 在仓库根目录重新生成并检查：

```powershell
python -X utf8 tools/progress/build.py
python -X utf8 tools/progress/build.py --check
```

首次克隆仓库后执行一次 `git config core.hooksPath .githooks`。启用后，提交只要动到根 README/AGENT、`doc` 下 Markdown 或生成器，`.githooks/pre-commit` 就会自动重新生成并暂存总览；生成失败（依赖缺失、编号或链接校验不通过）会直接阻断提交。未启用钩子时仍需手动执行上面两条命令。

生成器使用 Python 3.11 及锁定的 `markdown-it-py` 渲染依赖；仅生成时需要依赖，查看 HTML 无需安装。首次环境缺依赖时运行 `python -m pip install -r tools/progress/requirements.txt`。生成器校验 ID 唯一性、范围与细项映射、父模块覆盖、状态枚举、问题分类/类型/重要度/紧急度枚举与档位一致性、问题和材料引用、文档链接，以及生成结果是否过期；失败返回非零。输出只有本地 HTML，不修改业务数据。任一内嵌 Markdown、源数据或页面模板变化后都要重生成；页脚指纹覆盖内嵌文档，不是实时同步时间。

## 4. 归档与纠偏

持续维护的台账、需求和设计保持稳定路径，直接修订当前正文，普通修订历史查 Git。独立审阅与当次验证保留快照，不倒改历史数字；头部必须注明这是某一基点证据，并链接当前状态。根操作规范不继续追加批次完成流水账。

实际归档放在 `doc/99-归档/`，登记来源、归档原因、适用日期和当前替代入口，修复所有入链。不归档仍有效的业务需求与设计，不把未做能力当作过期文档删除。范围尚未逐合同映射、真实样本缺失、远程 CI 未验证等状态继续显式保留。

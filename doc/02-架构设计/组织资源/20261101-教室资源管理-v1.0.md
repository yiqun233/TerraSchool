# 教室资源管理

| 项目 | 内容 |
| --- | --- |
| 版本 | v1.0 |
| 状态 | 已实现，待项目负责人验收 |
| 创建日期 | 2026-11-01 |
| 更新日期 | 2026-11-01 |
| 维护 | AI协作者；项目负责人验收 |

教室归属单一租户和学校，记录名称、可选同校校区、可选容量（0至100000）及可用状态；支持列表、创建、修改、启停。ROOM_READ和ROOM_MAINTAIN独立控制，维护范围必须同时可读。学校及校区候选按权限过滤并支持远程搜索。

数据库联合外键防止跨学校和跨租户关联；创建请求身份支持同内容重放，修改需提交读取时的版本，冲突后重读。写入事务取得机构授权锁后复核会话及权限，成功前后快照和失败拒绝分别留审计。教室排课占用、设备及更丰富的场地信息不在本批。

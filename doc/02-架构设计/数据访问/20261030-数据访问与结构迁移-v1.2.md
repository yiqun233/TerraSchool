## 1. 已确认选择

采用 jOOQ 作为主数据访问方式，Flyway 管理数据库结构。MyBatis 保留为比较过的备选，不默认与 jOOQ 混用；JPA/Hibernate 不作为当前主要持久化方案。用户已接受，见 DEC-005。

业务层通过有明确职责的数据访问接口使用持久化能力，jOOQ 实现在模块内部。普通增删改查和复杂查询都采用一致风格，特殊原生 SQL 需要说明理由并验证参数、映射和隔离。

用户随后授权 R3 隔离原型：Flyway 12.4.0 → 临时 PG 18.6 → jOOQ 3.21.9 生成 → Java 21 / Boot 4.1.2 编译与真实测试主链通过，见[核心技术组合验证记录](../../03-研发规范/工程质量/验证记录/20261031-核心技术组合验证记录-v1.0.md)。不使用现有开发库或生产库，正式业务结构、JDK 发行版及完整交付组合继续验证。

## 2. 数据库结构与生成流程

版本化迁移脚本是目标数据库结构的权威定义，jOOQ 类型由该结构派生。构建与持续验证的目标流程：

```text
Flyway 迁移脚本
→ 隔离的临时 PostgreSQL
→ 应用全部目标迁移
→ 生成 jOOQ 表、字段等元数据
→ 编译业务代码
→ 真实 PostgreSQL 集成验证
```

不连接生产库生成代码，不依赖开发者个人库状态，不在客户服务器启动时生成代码。临时数据库的启动与缓存、生成产物是否入库由工程工具方案细化；必须可重复构建和核对结构。

生成类型可帮助发现字段删除、重命名和部分类型不匹配，前提是重新生成且查询使用这些类型。原生 SQL、动态字符串、过期生成元数据和业务逻辑错误不享有等同编译保障。

## 3. 模块边界与业务模型

- 生成代码属于对应模块内部，生成范围按数据所有权划分，避免全局表集合成为跨模块读写捷径。
- 不在领域对象、公开 DTO、应用契约或前端中暴露 DSLContext、jOOQ Record 和表字段类型。
- 跨模块使用公开业务契约；报表投影或经评审的跨域查询遵守所有权与授权要求。
- 领域规则使用清楚的业务对象和金额/课时类型，持久化记录不代替领域模型。
- Repository/查询实现只承担数据访问，不能成为另一套权限、资金和状态规则中心。

## 4. 事务与并发

应用服务确定事务边界，jOOQ 使用与其一致的数据源、连接和 Spring 事务管理。禁止同一业务用例内各数据访问方法私自提交，禁止混用独立连接导致部分操作脱离事务。

收款分配、关课入账、退款、转班与锁月等按照既定原子边界处理。数据操作检查影响行数，版本冲突、唯一约束与锁失败转为明确结果，不能静默当成功。

数据库约束、版本条件和并发协议仍需设计；jOOQ 不自动保证业务幂等、租户隔离和正确的锁顺序。任务、通知、模型和外部网络等待不占用长事务。

## 5. 查询与安全

使用参数绑定，动态排序和标识符来自允许集合，不拼接用户或模型输入为任意 SQL。查询、关联选项、统计、导出和下载应用统一租户与数据权限约束。

先过滤权限再分页，限制结果规模和查询成本，避免全量加载与逐条循环查询。复杂聚合验证关联基数，防止重复统计金额。SQL 能编译不代表权限正确或统计口径正确。

## 6. 迁移与交付

迁移脚本有顺序与校验，结构演进通过新迁移表达；已在共享环境执行的脚本不原地修改。大或破坏性变更设计兼容、回填、校验和恢复/补偿步骤。

应用运行账号与迁移账号权限分开。标准 SaaS 的 tenant_id + RLS 已在 DEC-006 确认，普通运行角色不持有表所有权、超级用户或 BYPASSRLS，租户业务表启用并强制 RLS；具体角色和策略配置在实现前验证。查询和写入在实际事务连接上绑定租户上下文，缺失时拒绝，详见[多租户数据隔离](../租户隔离/20261030-多租户数据隔离-v1.1.md)。SaaS 和客户版使用同一结构演进基线；执行位置、流程和权限根据部署方案确定，不将“应用启动即拥有全部迁移权限”视为默认。

旧系统历史 SQL 是考证材料，不是新项目迁移集，不可直接重放。旧数据转换、清洗与业务对账属于迁移工具职责，和 Flyway 的目标结构升级区分。

## 7. 验证和代价

首次工程验证至少覆盖：结构迁移后的生成与编译、数值和时间类型映射、动态查询、事务回滚、版本冲突、影响行数、模块越界、租户/权限拒绝及重复操作。

这些验证使用与实际特性相符的 PostgreSQL 环境，不能以其他数据库的模拟结果代替。本轮已验证其中的迁移/生成、数值时间、事务回滚、版本条件、租户及入口权限；未验证全部模块越界、重复业务操作、完整并发和迁移升级，不宣称已生产可用。

代价包括 DSL 学习、元数据生成和构建管线维护。生成代码集中自动管理，中文注释聚焦手写业务规则、查询语义和边界；不手改生成文件。

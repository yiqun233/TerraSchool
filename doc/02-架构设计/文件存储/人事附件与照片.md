## 范围和授权

人员档案可上传附件或照片、列出、下载和移除；照片按附件处理，不自动公开或在页面中嵌入。每个活动附件不超过5 MiB，每名员工最多100个活动附件。上传与移除要求同校人事维护和员工维护；列表与下载要求人事读取和员工读取。停用学校保留历史下载，禁止新建和移除。移除是保留历史的软移除，不立刻删除对象或绕过备份保留策略。

对象存储和凭据只在服务端配置，浏览器不获得桶名、对象地址或密钥。下载强制附件形式、禁嗅探并禁缓存；文件名不得为路径或含控制字符。应用计算 SHA-256 并在下载时核验内容。失败和拒绝记录操作结果，成功上传、下载与移除记录操作事件，不记录文件内容和文件名。

## 重试与恢复

上传需要唯一请求身份，相同主体、相同员工、名称及内容重放返回原附件；更换内容产生冲突。上传前将无正文的预留独立提交；对象写入与业务记录不能假定为跨数据库和S3的原子事务。若进程中断或事务回滚，可使用原请求身份重试。预留超过24小时且没有任何附件记录引用时，租户后续上传在机构锁内最多清理3个确认为该租户的孤儿对象；已引用及软移除附件不会被此机制删除。

这是一种机会式清理，不是定时任务：若租户不再上传，过期预留与孤儿对象会继续保留，后续需要受控运维核对。上传不支持嵌入已有外层业务事务。S3调用有界超时；实际服务的稳定性、桶私有策略、备份/恢复和保留期仍需单独验证。

S3 客户端使用 AWS SDK for Java 2.x 的 [S3上传接口](https://docs.aws.amazon.com/sdk-for-java/latest/developer-guide/best-practices-s3-uploads.html)，本地使用 path-style 兼容接口。开发环境可在受保护的 `.local/dev/storage.json` 配置 `endpoint`、`region`、`bucket`、`access-key`、`secret-key`，再运行 `python -X utf8 tools/dev/run.py prepare`。不得将该文件或密钥提交到仓库；生产应使用专用最小权限身份和私有桶。

## 本机真实验收

用户在2026-11-01明确选择本地使用WSL现有共享开发身份，应用仅生成 `teraschool/personnel/` 项目附件前缀下的键。该身份具有较大权限，仅供本机开发；生产须使用独立最小权限身份与私有桶。凭据已放入受限本地配置，不进入文档或仓库。

以合成文本通过真实HTTP及SeaweedFS完成上传、同请求重试、下载、只读账号拒绝及软移除；对该合成对象的匿名读取被拒绝。验收附件已软移除，对象依保留策略仍在项目附件前缀中；本次未清理共享桶。该检查不等于整桶所有对象的私有策略、生产安全或备份恢复已验证。

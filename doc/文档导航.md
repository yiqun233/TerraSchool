| 最初业务依据和待确认基线 | 功能全集、业务规则、05 的 BQ/DATA/TECH 清单及 06 旧系统证据 |

## 4. 维护方式

- 持续维护文档路径固定，版本只写正文；普通修订/升版不改文件名和入链。新增、删除、搬迁或实际更名时才更新本目录及相关引用，见[文档管理规范](03-研发规范/文档管理规范.md)。
- 验证记录与独立审阅/验收快照保留日期、文件名不带版本；历史由 Git 保存，不创建平行“最终版/新版”。
- 开发每批更新受影响 F 行和 REV 任务，设计维护规则，验证记录维护实际结果，问题登记维护确认结论；导航和 README 只作入口。
- 旧资料位于本机 `参考资料/`，只读、不提交、不随仓库分发、不参与产品构建。旧行为是证据，不自动成为正确业务结论。
- 链接、元数据和索引覆盖通过不等于语义全部一致；本轮发现与未审范围见审阅报告及验证记录。

# G4 统一字典维护验证记录

## 本次范围

新增学校级字典项的目录维护切片：组织维护者可选择有维护权限的学校，以稳定字典代码和项代码列示、增加、改名、排序及软停用字典项。字典项有版本号；创建使用稳定请求身份；停用保留历史行和审计，不允许物理删除、改码或复用代码。读取只返回启用项，可显式查看停用项。

## 验收证据

- 后端 `OrganizationMaintenanceTest`：13 项通过，覆盖读/写学校范围、类别与项代码校验、稳定代码冲突、幂等同参重试/异参拒绝、版本冲突、软停用、业务审计数量、OpenAPI 路径，以及 HTTP 非法读取被拒绝时的独立失败审计。
- 前端 `DictionaryWorkspace.test.tsx`：2 项通过，覆盖创建提交与版本化停用。
- 前端 TypeScript、ESLint、生产构建通过；代码由 OpenAPI 契约生成客户端类型。Vite 提示主包超过 500 KB，是构建体积提示，不影响构建成功。
- 数据库迁移 `V75__school_dictionary.sql` 启用租户 RLS 并限制应用角色表权限；`V76__dictionary_failure_audit.sql` 将三个字典动作纳入失败审计代码约束。

## 暂行规则与未决项

该实现是 REQ-A20 的可用首切片，不代表统一字典中心验收完成。当前范围按学校隔离，类别由录入的稳定代码隐式建立；未支持租户共享/继承、平台预置类别、批量导入、业务字段映射及引用情况报告。上述边界登记在 Q75，须确认正式目录模型和岗位矩阵后继续扩展。

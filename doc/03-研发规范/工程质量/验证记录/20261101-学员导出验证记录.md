学员 CSV 导出，验证"导出不会绕过字段级权限"这一此前未覆盖的路径，并补导出审计。

## 3. 结果

| 场景 | 结果 |
| --- | --- |
| 只有 `STUDENT_READ` 的账号导出 | CSV 中电话为 `138****1111`、证件为 `****1234`，不含完整值 |
| 额外授予 `STUDENT_PHONE` | 电话完整、证件仍脱敏 |
| 导出不在读取范围内的学校 | 拒绝（`AccessDeniedException`） |
| 导出动作 | 写 `STUDENT_EXPORTED` 审计（含行数） |

## 4. 限制

- 只有学员域有导出；报名/收款/课次导出未接入；
- 导出上限 5000 行，超出需要用报表或分批导出；
- 导出为同步下载，未做异步任务与导出文件留存。

## 3. 覆盖到的行为

| 主题 | 用例与结果 |
| --- | --- |
| 价格快照 | 报名返回冻结的 `1000.00` 元 / `10.00` 课时与净应收；后续改价不影响该报名（本批以快照字段与只读校验覆盖） |
| 幂等 | 同请求号重试返回同一报名；换日期重试返回 `IDEMPOTENCY_MISMATCH`；成功审计只有一条 |
| 可售校验 | 草稿价格与生效日期之前的报名都被 `PRICE_VERSION_NOT_SELLABLE` 拒绝 |
| 审核独立 | 只有登记权限的账号审核被拒；过期版本 `VERSION_CONFLICT`；重复审核 `ENROLLMENT_NOT_PENDING` |
| S1 收款 | 收款确认后账户总额 `1000.00`，可用金额 `1000.00`，收款可用 `1000.00` |
| S2 分配 | 全额分配后未收金额 `0.00`、账户总额 `0.00`、已分配 `1000.00` |
| 超分防护 | 分配超过收款可用返回 `RECEIPT_INSUFFICIENT`；超过报名未收返回 `ENROLLMENT_OVERPAID` |
| 报名状态 | 未审核报名不能分配，返回 `ENROLLMENT_NOT_ACTIVE` |
| 学员一致 | 用其他学员的收款分配返回 `STUDENT_MISMATCH` |
| 释放 | 释放后报名未收恢复 `1000.00`，收款可用恢复 `1000.00` |
| 撤销收款 | 有有效分配时撤销被拒（`RECEIPT_HAS_ALLOCATIONS`）；释放后可撤销，账户总额归零而报名未收恢复 |
| 收款幂等 | 同请求号重试不重复写账户流水（按来源计数为 1） |
| 并发 | 同一收款并发送出两笔 600 元分配：恰好一笔成功、另一笔按命中规则被拒，余额剩余 `400.00`，未出现超分 |
| 权限分离 | 只读账号收款与分配均被拒 |
| 租户隔离 | 跨租户写入被强制 RLS 拒绝（SQLState 42501） |
| 第二入口 | 真实 HTTP：登记 201 且金额为字符串、仅登记权限审核 403、收款 201 金额字符串、余额 200 且金额为字符串 |

## 4. 限制与未覆盖

- 远程 GitLab Runner 仍未确认，本记录只代表本机执行结果。
- 退课时、退费与现金退出（SC01 S5–S7）未实现；退款时的应收减项、分配释放与账户退回在下一批。
- 定金/尾款、发票、优惠减免、服务费独立结算、锁月与财务期间未实现。
- 收款为线下实收登记，未接银行或支付渠道，也未记录票据号。
- 学员选择依赖档案读取权限；接口本身只要求报名动作，页面受此限制。
- 首次生产管理员初始化、密钥轮换与恢复演练不在本批范围。

## 5. 复现要点

```powershell
python tools/engineering/verify.py

cd backend
./mvnw -B test -Dtest=EnrollmentAndReceiptTest
```

失败/拒绝审计新增动作：`ENROLLMENT_CREATE`、`ENROLLMENT_APPROVE`、`RECEIPT_CONFIRM`、`RECEIPT_VOID`、`ALLOCATION_CREATE`、`ALLOCATION_RELEASE`。资金审计额外记录金额，报名审计只记录动作与变化字段。

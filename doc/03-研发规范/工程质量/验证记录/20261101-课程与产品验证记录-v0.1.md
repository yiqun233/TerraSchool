## 3. 覆盖到的行为

| 主题 | 用例与结果 |
| --- | --- |
| 幂等创建 | 同请求号重试返回同一课程；换参数返回 `IDEMPOTENCY_MISMATCH`；审计只有一条 |
| 课程名称唯一 | 同校同名返回 `409 DUPLICATE_CURRICULUM_NAME` |
| 课程归属 | 产品引用的课程必须属于同一学校，跨校返回拒绝且不泄露存在性 |
| 金额表示 | `"1000"` 规范化为 `"1000.00"`；三位小数、零值、负值、日期倒置均按无效输入拒绝 |
| 发布权限 | 只有维护权限的账号发布价格被拒；具备 `PRICE_PUBLISH` 的账号可发布 |
| 发布不可改写 | 已发布版本再次修改返回 `PRICE_VERSION_IMMUTABLE` |
| 版本替换 | 发布新版本使旧发布版本转为 `RETIRED`，目录只返回新版本作为当前价 |
| 可售窗口 | 业务日期在有效期内才可售；超出窗口、停用后均为空；日期格式错误按无效输入拒绝 |
| 版本并发 | 过期版本发布返回 `409 VERSION_CONFLICT` |
| 权限与范围 | 只读账号不能创建课程；跨学校目录查询被拒；DENY 覆盖 ALLOW 后该校不可读 |
| 租户隔离 | 跨租户写入被强制 RLS 拒绝（SQLState 42501） |
| 第二入口 | 真实 HTTP：只读目录 200、建课程 403（仅发布权限）、可售列表金额与课时为 JSON 字符串且结算模式为整数 |

## 4. 限制与未覆盖

- 远程 GitLab Runner 仍未确认，本记录只代表本机执行结果。
- 结算模式 0–5 仅作快照，公式与金标准未实现；优惠、服务费类型、券与可售范围矩阵未实现。
- 目录单校上限 500 条，未做分页；课程/产品无业务编号。
- 「我的权限」未展示 `PRODUCT_*` 与 `PRICE_PUBLISH`。
- 价格版本「同一产品仅一个已发布」是当前约定，多版本并行报价需另行确认。
- 首次生产管理员初始化、密钥轮换与备份恢复演练不在本批范围。

## 5. 复现要点

```powershell
# 全套检查（需要 JDK 25 的 JAVA_HOME 与可用 Docker 引擎）
python tools/engineering/verify.py

# 只跑课程产品测试（需先准备临时库并设置 TS_* 变量）
cd backend
./mvnw -B test -Dtest=ProductCatalogTest
```

失败/拒绝审计新增动作：`CURRICULUM_CREATE`、`CURRICULUM_UPDATE`、`PRODUCT_CREATE`、`PRODUCT_UPDATE`、`PRICE_VERSION_CREATE`、`PRICE_VERSION_UPDATE`、`PRICE_VERSION_PUBLISH`、`PRICE_VERSION_RETIRE`。

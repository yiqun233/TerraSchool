# G4 单班自动排课验证记录

状态：REV-011 的单班固定周次资源自动选择及多班顺序协调切片已实现并通过后端验证；教师资格/校历等业务约束仍未完成，见 Q61。

## 当前规则

- 预览/确认可启用“自动选择教师与教室”；未指定实体资源时，从该校启用资源中按名称、ID 稳定排序。
- 教室容量小于当前在班人数时排除；无学生的班级可使用容量为 0 的教室，未配置容量的教室视为容量未知且可选。
- 系统评估一个固定教师/教室组合在本组所有周课时段的硬冲突，优先选择可行课次数最多的组合；同分时沿稳定排序选择。确认后所有草稿课次引用所选教师/教室实体并保留名称快照。
- 若无教师或无容量合格教室，分别报告 `NO_TEACHER_CANDIDATE` / `NO_ROOM_CANDIDATE`；若组合均被硬冲突阻断，报告 `NO_FEASIBLE_RESOURCE_PAIR`。部分日期仍可排时会保留候选组合，并逐日展示已有冲突。
- 自动选择不改变原有确认幂等、课次状态机及 WARN 显示；预览不写库，确认重新计算并在租户锁事务内创建。
- 多班请求一次最多 20 个班、400 个候选课次；班级 ID 不得重复。预览按请求顺序将前序可用课次作为临时教师/教室占用，后续班据此选择资源；确认在单个租户锁事务内逐班重新计算并写入，任一班失败时整批回滚。
- 工作台提供多班自动排课入口；当前批量 UI 统一设置相同日期、星期和时间规则，资源由系统自动选择。复杂的交换搜索/全局最优分配尚未实现。

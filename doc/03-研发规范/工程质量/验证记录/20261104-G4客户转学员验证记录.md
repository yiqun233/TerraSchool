# G4 客户转学员验证记录

状态：REV-009 已增加负责人客户到新学员档案的首个事务化转换入口；同校学员重复合并、转换撤销与负责人最终规则仍未验收，见 Q58。

## 当前候选行为

- 仅客户当前负责人可操作；须同时具有该校客户维护、学员维护和完整电话查看权限，学校必须启用。
- 不在公海或已合并的客户才可转换；请求明确填写学员姓名和客户联系人关系，使用版本号和请求摘要幂等保护。
- 学员、以客户姓名/电话建立的主要联系人、客户与学员来源关联在同一租户事务提交。事务失败时学员、联系人和关联一起回滚；客户档案保留，关联包含操作负责人。
- 学员重复提示由档案域返回，不自动合并；客户合并与学员合并仍是不同业务动作。页面不回显客户电话。
- 转换关联创建后暂不支持撤销；改错或撤销的业务路径待负责人确认。

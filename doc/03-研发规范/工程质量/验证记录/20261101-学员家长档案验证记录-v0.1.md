## 3. 覆盖到的行为

| 主题 | 用例与结果 |
| --- | --- |
| 创建与联系人 | 创建返回 `S` + 6 位学员号、联系人关系与主要标记；成功审计与业务同事务，模型变更后旧结果不被改写 |
| 幂等 | 同请求号重试返回首次结果；换参数返回 `409 IDEMPOTENCY_MISMATCH`；HTTP 与直接入口表现一致 |
| 证件唯一 | 同租户同证件类型同号码返回 `409 DUPLICATE_CERTIFICATE`，由数据库唯一索引兜底 |
| 重复提示 | 同名同生日返回 `SAME_NAME_AND_BIRTHDAY` 提示且不阻断、不合并；联系人仅姓名与电话都一致才复用 |
| 敏感字段 | 无 `STUDENT_SENSITIVE_READ` 时电话为 `138****5678`、证件号为 `****1234`、生日只到年月；有该权限时返回原文并写 `STUDENT_SENSITIVE_READ` 审计 |
| 数据范围 | 列表按学校范围过滤后再分页；越界学校创建被拒；只读账号不能创建 |
| 停用学校 | 学校停用后创建、修改、改状态均被拒（与学校生命周期共用机构锁） |
| 版本并发 | 过期版本返回 `409 VERSION_CONFLICT`；状态单独变更按版本条件更新并递增版本 |
| 脱敏回写 | 提交脱敏邮箱被拒绝，避免把掩码写成权威值；状态变更使用独立操作，不提交敏感字段 |
| 租户隔离 | 跨租户写入被强制 RLS 拒绝（SQLState 42501） |
| 第二入口 | 真实 HTTP 登录 + CSRF：无令牌写请求 403、创建 201 且返回脱敏值、列表总数与直接调用一致、重试与换参数符合幂等规则 |

## 5. 复现要点

```powershell
# 全套检查（需要 JDK 25 的 JAVA_HOME 与可用 Docker 引擎）
python tools/engineering/verify.py

# 只跑学员档案相关测试（需先按验证脚本准备临时库并设置 TS_* 变量）
cd backend
./mvnw -B test -Dtest=StudentProfileTest
```

失败/拒绝审计的动作名新增 `STUDENT_CREATE`、`STUDENT_UPDATE`、`STUDENT_SENSITIVE_READ`；`audit.student_event` 只保存动作与变化字段名称，不保存证件号、电话等正文。

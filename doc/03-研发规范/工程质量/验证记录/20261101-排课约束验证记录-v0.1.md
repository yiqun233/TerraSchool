## 3. 结果

| 场景 | 结果 |
| --- | --- |
| 教师 2026-10-03 08:00–12:00 休假 | 该日候选为 `TEACHER_UNAVAILABLE` / HARD，另一周六仍可排 |
| 教室 2026-10-17 被预订 | 该日 `ROOM_UNAVAILABLE` |
| 策略把"教师不可用"降为警告 | 同一天变为 `WARN` 且 `available=true`（可排但有警告） |
| 最小间隔 30 分钟，教师 08:00–09:00 已有课 | 09:00 的候选返回 `TEACHER_MIN_GAP` |
| 同时给教师与教室 | `RESOURCE_REQUIRED` |
| 策略更新 | 过期版本 `VERSION_CONFLICT`；正确版本保存后版本递增 |

## 4. 维护界面

教学页「排课设置」：不可用时间页签可新增并列出（教师/教室、日期、时段、原因），策略页签可改两个阻断开关与最小间隔并带版本保存。前端测试 20 个文件 45 项 → 22 个文件 47 项。

## 6. 限制

- 无学员休假、班级休息日、跨校距离、座位数与教室生命周期；
- 无深度交换搜索；
- 阻塞与策略暂无前端维护界面。

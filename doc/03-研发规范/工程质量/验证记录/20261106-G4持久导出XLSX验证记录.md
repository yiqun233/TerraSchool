# G4 持久导出 XLSX 验证记录

状态：四类持久导出（学员、报名、收款、课次）已增加 CSV/XLSX 格式选择。该记录证明工程切片和定向回归通过，不代表 REV-013 完整验收。

## 实现范围

- `infra.export_task.export_format` 固化每个任务的 `CSV` 或 `XLSX` 格式；数据库约束拒绝未知格式。
- 请求幂等摘要包含类型、格式和固定日期范围；相同请求标识改用另一格式会被拒绝。原学员 CSV 幂等摘要保持兼容。
- CSV 保持原内容。XLSX 由 Apache POI 6.0.0 写成单工作表，CSV 引号/逗号/换行按记录解析，单元格均写成字符串，输入以 `=` 开头时也不会形成 Excel 公式。
- 下载返回对应 MIME 类型和 `.csv`/`.xlsx` 文件名；三类通用导出工作台及学员档案工作台均可创建 CSV/XLSX 任务。
- 数据查询在任务执行时进行并固化结果，创建时数据快照语义仍待 Q63 确认。

# G4 仅服务费报名验证记录

状态：仅服务费产品价格和报名首切片已实现；多产品/多班报名已沿用批次接口，但转班、退班、延期和定金转报名尚未完成。当前仅服务费规则是工程约束候选，财务服务费退费仍按旧项目调查并由 Q50/Q60 跟踪，负责人尚未验收。

## 实现边界

- 产品价格允许两种形态：课程价与课时均大于零（服务费可为零或正数）；或者课程价、课时都为零且服务费大于零。全零产品、仅课程价为零、仅课时为零均拒绝。
- 报名冻结课程价 `0.00`、课时 `0.00` 和独立服务费；总应收仍由课程价加服务费组成。仅服务费报名不写入虚构课程明细，因此不能产生课时消费/退课时。
- 产品和报名列表将此类记录标为“仅服务费”，避免展示成普通零价/零课时课程。
- 普通课程优惠入口拒绝仅服务费报名；此类费用应走独立服务费调整策略，当前服务费减款审批执行器尚未接入。

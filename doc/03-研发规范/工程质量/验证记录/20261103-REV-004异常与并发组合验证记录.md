## 发现和修复

- 学校停用规则遗漏 9 个写入口：教务的发布、考勤确认、关课、期初消费；资金的撤销收款、分配、释放分配、退款已付及取消未付退款。已在机构锁内、范围检查后补学校启用检查，历史查询仍可用。
- PermissionRules 的可管理动作目录遗漏现有 REFUND_READ、REFUND_APPLY、REFUND_PAY，公开授权替换会报“无效权限规则”。已补目录，撤权组合通过公开授权服务验证。
- 新 SQL 门禁最初会漏掉分段常量写表，独立评审后改为折叠相邻常量并增加普通字符串、分段表名、大小写及 text block 反例。全后端首轮暴露 Java Unicode 分隔符解析错误，已增加词法前 Unicode 解码及反例，并统一实际引用和写表扫描的大小写处理。变量表名仍不在静态解析保证范围内。
- 工程脚本改用 TCP pg_isready，避免 PostgreSQL entrypoint 初始化时的临时 Unix socket 服务被误判就绪。

首轮夹具学号超长、首次容器就绪竞态及退款动作目录导致的失败均已纠正。修复前运行 `cb313479e310` 的停校关课/已付排队用例确实放行；这些失败保留于本地原始日志，不将修复前运行算作通过。

## 3. 结果

| 场景 | 结果 |
| --- | --- |
| 收款导出（学校 + 日期范围） | 表头正确，含学员号与金额；写 `RECEIPTS_EXPORTED` 审计 |
| 报名导出（学校） | 表头含净应收等 9 列；写 `ENROLLMENTS_EXPORTED` 审计 |
| 课次导出（学校 + 日期范围） | 表头正确，含日期与时间；写 `LESSONS_EXPORTED` 审计 |
| 导出范围外学校 | 三个导出都拒绝 |

## 4. 实现要点

- 净应收不落列，导出时按 `sum(charge.amount)` 现算，与详情口径一致；
- 导出上限 5000 行，避免同步下载拖垮请求；
- 前端「导出 CSV」/「导出课次」按钮走浏览器下载，不经过前端拼装数据。

## 5. 限制

- 收款导出只有接口与按钮位置在报名页（资金页尚未独立），暂未做独立资金台账页；
- 没有异步导出、文件留存与下载历史；
- 导出列固定，不支持自定义列。

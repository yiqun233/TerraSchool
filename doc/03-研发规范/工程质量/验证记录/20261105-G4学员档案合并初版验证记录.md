# G4 学员档案合并初版验证记录

状态：REV-009 学员档案合并/撤销已有可运行的受限初版；主档/冲突字段/关联迁移/自动回收等负责人规则仍待确认，不视为 REV-009 整体验收。

## 暂定实现边界

- 仅允许同校、同负责人、双方有效且操作者具备学员档案维护权限的合并。
- 源档必须没有报名历史、资金账户流水、收款/退款记录或招生客户来源关联。存在历史时拒绝合并，不搬迁联系人、报名、课时、收付款或来源关系。
- 操作者显式选择主档并填写原因。源档不物理删除，保留合并目标和时间；普通列表、导出及重复检查隐藏源档，跨域学员访问拒绝将它当作有效档案。
- 主档详情展示合并记录；有维护权限者可填写原因并以源档版本撤销。撤销时重查关联事实，只有此前仍未建立业务关联时才恢复源档。
- 合并和撤销均使用稳定请求号、参数摘要、事务、租户锁、版本条件更新及审计；同请求同参数返回首次结果，参数不一致拒绝。
- 不做客户或学员自动回收；不允许跨校/跨负责人合并，也不自动选择主档或覆盖字段。

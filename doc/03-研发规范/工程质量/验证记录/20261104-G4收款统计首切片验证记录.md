# G4 收款统计首切片验证记录

状态：学校级日收款分组统计已实现并通过集成回归；候选业务口径尚待负责人确认，不代表 11 项报表验收。关联 REV-012、F28、Q62。

## 范围

- 新增 `GET /api/finance/reports/receipt-daily?schoolId=&from=&to=`。
- 使用现有 `FUNDS_READ` 学校权限，查询事务内再次复核权限；不同学校数据不返回。
- 按收款发生日、收款方式、单据状态分组，返回单据数与收款单原始金额；`CONFIRMED` 和 `VOIDED` 分组展示，未把作废额抵销或把现金退款合并进统计。
- 日期必须为 `YYYY-MM-DD`，结束日不得早于起始日，查询跨度最多 367 个自然日。
- 本切片不支持校区分组，也不将统计字段命名为净实收或确收收入。

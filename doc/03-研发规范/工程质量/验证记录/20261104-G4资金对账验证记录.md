# G4 学校资金总账对账验证记录

状态：一项确定性全量累计资金平衡式已实现并验证；Q62 所列其他报表口径和负责人验收仍未完成。

## 计算口径

单校全体学员以当前学员归属学校 `archive.student.school_id` 汇总原始资金账：

`期初余额 + 净收款（收款与撤销收款分录） - 已支付现金退款 = 有效收款分配 + 学员账户余额`

API 的 `cashRefundAmount` 以正数展示；底层资金账现金退款是负数。金额以十进制字符串返回。仅授予该校 `FUNDS_READ` 的账号可读取。全部为全量累计，不按年份、业务日期或财务期间过滤。其他跨校转移归属未实现；Q62 需确认正式报表所用学员/学校归属规则。

## 边界

- 这是账本关系核验，不是期间收入确认、收款日报、班级/学校收入或经营报表。
- `archive.student.school_id` 是当前归属口径；正式跨校共享/转校后的历史归属口径未确认。
- 退款只统计已写入资金账户流水的现金退款；准备中冻结单不属于已付退款。该视图不展开冻结金额或支付渠道对账。

# G4 部分缺勤验证记录

状态：部分缺勤的实际分钟记录与按比例消费已实现候选规则；课时精度及最低计量规则待 Q61 确认。

## 当前候选规则

- 考勤仍须覆盖所有在班报名；状态支持出勤、部分缺勤、缺勤和请假。
- 部分缺勤需提供大于 0 且小于该课次排课时长的实际出勤分钟；其它考勤状态不可附带分钟值。
- 消费课时按“课次课时 × 实际出勤分钟 ÷ 排课分钟”计算，四舍五入到 0.01 小时；折算为 0.00 时在考勤确认阶段拒绝，避免留下不能关课的确认记录或登记出勤却不产生消费。
- 退款/课时上限、模式计价和尾差均基于折算后的实际消费课时；金额与课时在同一关课事务中写入。

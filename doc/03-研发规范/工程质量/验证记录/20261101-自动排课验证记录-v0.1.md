## 1. 本批范围

单班、按周几与固定时段的批量排课：预览（不写库）、确认（写草稿课次）、四类冲突跳过与原因、重复确认幂等，以及前端"自动排课"弹窗。

## 3. 结果

| 场景 | 结果 |
| --- | --- |
| 2026-05-02–05-23 每周六 09:00–10:00 | 预览 4 个候选全部可排；确认生成 4 条 DRAFT |
| 同一规则再次确认 | 创建 0、跳过 4，原因全部 `DUPLICATE` |
| 另一班用同一教师同一时段 | 全部 `TEACHER_CLASH` |
| 另一班用同一教室同一时段 | 全部 `ROOM_CLASH` |
| 只预览不确认 | 该班课次仍为空 |
| 未选周几 / 结束早于开始 / 超过 180 天 | 分别返回 `SCHEDULE_WEEKDAY_REQUIRED`、`SCHEDULE_TIME_INVALID`、`SCHEDULE_RANGE_TOO_LONG` |
| 只有 `TEACHING_READ` 的账号排课 | 拒绝（需要 `TEACHING_MAINTAIN`） |
| 跨租户写课次 | 强制 RLS 拒绝（SQLState 42501） |

## 4. 前端

"课次"卡片新增「自动排课」按钮：填写日期范围、周几、时段、课时、教师与教室后可先"预览"，表格逐行显示可排/跳过与中文原因；有可排时段时才能"确认生成"，确认后生成草稿课次并刷新列表。预览卡片的渲染有独立组件测试。

## 5. 教师/教室实体化

| 场景 | 结果 |
| --- | --- |
| 用实体创建课次 | 课次保存 `teacher_id`/`room_id`，名称取实体快照（张老师 / A101） |
| 用外校教师 | `RESOURCE_NOT_IN_SCHOOL` |
| 用停用教师 | `RESOURCE_INACTIVE` |
| 两个班用同一教师实体排课 | 第二个班全部 `TEACHER_CLASH`，与名字是否相同无关 |
| 排课时用外校教师 | `RESOURCE_NOT_IN_SCHOOL` |

后端测试 197 → 202 项。

## 6. 限制

- 不做自动选教师/教室：软约束（活动、休假、预订、座位、距离）未确认，不能假装能选；
- 不做锁定课次保护（本轮只新增，不重排）；
- 无最小课间间隔、午休/晚休、休息日与节假日；
- 无多班联合与失败后的交换搜索；
- 教师与教室仍是自由文本，未关联员工/教室实体。

# G4 审批闭环扩展验证记录

状态：审批申请幂等、审批单生命周期和动作目录的代码回归已通过；不代表六类业务动作全部完成，负责人尚未验收。关联 REV-012、F27、待确认问题 Q55 与 Q65。

## 本次变更

- 审批动作目录扩展为：转班、退班、延期、报名减款、服务费减款，并保留退课时、现金退款、优惠、服务费退费与服务费退费冲正。
- 申请人可按版本撤回本人仍待审的审批单；他人不可撤回，已处理单据不可再次撤回。
- 有审批决定权限且非申请人的审批人，可写明原因将待审单设为失效；状态和版本在同一事务更新，并写入审批审计。
- 审批申请使用持久请求标识和规范化参数摘要；同一申请人以相同标识/参数重放返回原审批单，改动参数复用旧标识会被拒绝。数据库咨询锁串行化同标识并发请求，RLS 限定租户；重放仍复查当前业务权限、学校范围和原申请人。
- 申请权限沿用现有权限目录按动作区分：转班/退班/延期要求报名维护，报名优惠/减款要求优惠权限，退款/服务费动作要求退款申请权限。缺少对应权限时拒绝；岗位正式矩阵仍待确认。
- 前端在申请内容变化时换发请求标识；发生网络中断时保留当前身份供原内容重试，409 时提示刷新核对而不关闭表单。
- 审批工作台显示全部申请状态；通过操作仅对待审单显示。新动作当前可申请/审批/失效，但转班、退班、延期和减款执行器尚未接入，不能用批准状态直接代替业务动作。

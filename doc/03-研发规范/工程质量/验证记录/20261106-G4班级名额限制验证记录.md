# G4 班级名额限制验证记录

## 范围

为报名、批量入班和转班补充班级容量上限。当前规则为候选规则，最终业务口径仍由负责人确认（Q71）。容量在建班时设置，取值 `0..100000`；`null` 表示不限，`0` 表示不允许新增成员。班级满额时拒绝单次入班、批量入班和转班；批量操作保持原子性。容量拒绝不得消耗转班审批或改变原班成员。当前暂不支持建班后的容量修改及候补。

## 实现

- 数据库为班级增加受范围约束的 `capacity` 字段。
- 创建班级时校验容量范围，容量也纳入幂等请求摘要。
- 班级列表和创建表单展示/设置名额；加入与转班执行端检查成员数，避免只依赖界面校验。
- 已存在成员重复加入时仍幂等成功；容量不足的批量操作整体回滚。

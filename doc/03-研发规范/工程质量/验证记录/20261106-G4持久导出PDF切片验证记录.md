状态：四类持久数据导出已加入 PDF 输出格式和服务端渲染切片；数据任务、前端按钮、迁移与安全 HTML 构造定向验证通过。真实 Chromium PDF 渲染未完成，REV-013 未关闭。

范围：REV-013 / F29，学员、报名、收款、课次四类既有持久导出。

## 实现

- 新增 PDF 任务格式；格式参与请求指纹，防止同一请求号跨格式复用。
- 任务使用服务端生成的 CSV 数据快照，不接受任意 HTML/脚本/URL；字段和行顺序直接沿用已有导出查询。
- CSV 单元格转成静态 HTML 表格并做 HTML 字符转义，关闭浏览器 JavaScript；固定 A4、12mm 页边距，启用重复表头样式。
- PDF 下载使用 `application/pdf` 与 `.pdf` 扩展名；列表、取消、重试、保留、权限复核复用原持久任务机制。
- Playwright Java 固定为 1.64.0。运行环境须另行安装匹配 Chromium、系统依赖和中文字体；未配置浏览器时任务按现有重试/失败路径处理。

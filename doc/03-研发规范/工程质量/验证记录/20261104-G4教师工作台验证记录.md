# G4 教师本人工作台验证记录

状态：REV-011 的教师本人课表、本人任教班级名册与本人课次工作台只读切片已实现并通过全量后端及专项前端验证；教务全 P0 未完成。

## 实现边界

- 通过当前身份绑定的 `organization.employee.account_id` 找到有效教师档案，只返回该教师在明确日期范围内承担的课次；没有绑定教师档案或无授课课次时返回空结果。
- 单次查询最多 93 个自然日，课次最多返回 1000 条；响应包括课次时间、班级/课程、课题、教室、状态，以及授课班级和区间内课次数。
- 与学校教务全量班级工作台分开展示，不扩张现有学校级读取范围。
- 增加 `/api/teaching/me/classes/{id}`：在事务内重新校验当前身份，需账号绑定同校在职教师档案，且该教师在所选班级至少承担一节课；仅返回该班在班/离班名册和本人承担的课次，不返回联系方式等档案敏感字段。
- 教师工作台新增本人任教班级入口，侧栏展示班级摘要、名册和本人课次；接口拒绝未绑定教师身份或未任教该班的访问。

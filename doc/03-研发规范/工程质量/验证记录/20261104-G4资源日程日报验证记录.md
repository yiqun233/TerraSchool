## 当前查询行为

- `GET /api/teaching/reports/resource-daily-schedule?schoolId=…&day=YYYY-MM-DD&page=0&pageSize=100` 按调用者可读学校返回当日课次，按开始时间、班级名排序；支持零基页码，页大小 1–200，默认 100。
- 返回当前页的班级、时段、教师、教室、课题和课次状态，以及全日总数和未关联结构化教师/教室 ID 的总数。仅有旧名称文本但没有结构化资源 ID 的记录，仍计为未分配资源。
- 使用 TEACHING 学校读取范围，并在事务内复核权限；日期格式必须为 ISO 日历日；无资源或无课次时返回空列表/零计数。
- 该查询没有月/期间金额口径，不代表经营报表或导出已经完成。

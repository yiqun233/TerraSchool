# G4 换课与补课初版验证记录

状态：2026-11-05 同班换课与缺勤补课的首版闭环已完成后端全量回归，并通过新增前端定向用例。教学工作台整文件回归仍有 3 项既有班级取消/退班异步用例失败，不能记为整文件通过。

## 实现范围

- 已发布且尚无考勤/消费事实的同班课次，可原子交换时段；服务端校验资源冲突并留存变更前后时段历史。
- 已关闭且有 ABSENT/LEAVE 学员的课次，可按原课次、同班、教师、教室和课时创建后续补课草稿；该草稿随后沿正常发布、考勤、关课和消费流程执行。
- 补课考勤只允许原课次缺勤/请假的学员计为出勤，防止已经出勤的学员重复消费课时。
- 换课和补课均使用请求身份、摘要及业务记录防重；接口失败审计已覆盖新增路由。
- 暂未实现审批门槛、通知、跨班/换教师/换教室及截止时间策略；这些口径继续登记在 Q73。

- 调课、换课、补课是否需要审批及其额度、角色、截止点和通知要求待 Q73 确认。

- 本记录只证明本初版实现范围，不代表 REV-011 或 G4 完成；班级全生命周期、校历/资质/路程约束、排课无解原因和教师工作流仍有后续工作。

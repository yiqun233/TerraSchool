# G4 多产品报名验证记录

状态：同一学员一次提交多个不同产品的报名首切片已接入工作台，并通过后端隔离数据库集成测试和前端组件测试；同一批多个班级的入班、插班、仅服务费报名、定金转报名和反审核仍未完成，业务关系见 Q60。

## 已实现行为

- 招生人员在同校报名工作台检索并选择一名学员，再选择至少两个可售产品。
- 服务端限制每批 2～10 项；所有项须属于同一学员、同一学校且使用不同产品；每项必须有独立请求 ID 和已发布价格版本。
- 所有报名在同一租户事务内创建；任何一项校验失败，整批写入、审计和幂等请求记录一并回滚。
- 每项沿用单产品报名冻结逻辑，分别保存价格/课时/服务费快照和课程明细；重复提交同一组子请求 ID 时回放既有报名，不重复创建。
- 前端对 5xx/网络异常保留原请求 ID 与内容，明确结果未知时可用相同请求重试；确定性拒绝则清除本次请求，允许修正后重提。

## 3. 覆盖到的行为

| 主题 | 用例与结果 |
| --- | --- |
| 班级创建 | 返回在班人数；同校同名 `DUPLICATE_CLASS_NAME`；跨校课程被拒；同请求号重试返回同一班级且审计一条 |
| 入班 | 报名加入班级后在班人数为 1；重复加入保持幂等；同一报名换班返回 `ENROLLMENT_ALREADY_IN_CLASS` |
| 状态机 | 草稿关闭返回 `LESSON_NOT_CONFIRMED`；发布后再次发布返回 `LESSON_NOT_DRAFT` |
| 考勤覆盖 | 缺少在班报名返回 `ATTENDANCE_MUST_COVER_MEMBERS`；重复报名或未知状态按无效输入拒绝；成功确认后状态为 `CONFIRMED` 且考勤条数为 1 |
| 消费固化 | 关闭后消费 1.00 课时 / 100.00 元，单价快照 1000.00；对账 购买 10.00 = 已消耗 1.00 + 剩余 9.00 |
| 缺勤不消费 | 考勤为缺勤时消费 0.00 课时，剩余仍为 10.00 |
| 重复关闭 | 再次关闭返回 `LESSON_NOT_CONFIRMED`，数据库消费记录仍为 1 条 |
| 累计消费 | 两次关闭后累计 2.00 课时 / 200.00 元，剩余 8.00 |
| 权限分离 | 只有考勤权限的账号关闭课次被拒；只读账号不能建课次、不能读对账 |
| 租户隔离 | 跨租户写入被强制 RLS 拒绝（SQLState 42501） |
| 并发关闭 | 两个请求同时关闭：恰好一个成功，另一个按状态或版本冲突返回；消费仍为 1.00 课时 |
| 审计 | 同一课次留下创建、发布、考勤确认、关闭四条记录，可还原生命周期 |
| 第二入口 | 真实 HTTP 走完 建课 → 发布 → 考勤 → 关闭，对账返回字符串课时与金额 |

## 4. 限制与未覆盖

- 远程 GitLab Runner 仍未确认，本记录只代表本机执行结果。
- 自动排课（单班/多班）、教师/教室占用与冲突、容量、补课换课、停课与锁定均未实现。
- 消费纠错与冲销单据未实现；课次关闭后不可回改。
- 退课时（S5）未实现，因此对账等式暂为「购买 = 已消耗 + 剩余」。
- 发布与维护共用 `TEACHING_MAINTAIN`，发布确认凭证未实现。
- 首次生产管理员初始化、密钥轮换与恢复演练不在本批范围。

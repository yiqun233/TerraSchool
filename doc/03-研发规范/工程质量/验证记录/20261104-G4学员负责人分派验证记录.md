# G4 学员负责人分派验证记录

状态：2026-11-04 学员负责人同校分派切片已实现并通过后端、前端回归；默认归属及岗位可见范围待负责人确认（Q69），REV-009 未关闭。

## 本次实现范围

- 新增独立 `STUDENT_ASSIGN` 学校范围权限；目标必须是同校有效员工且具有关联账号。
- 学员详情可查看当前负责人和有权分派的负责人选项；提交包含学员版本、原因和稳定请求身份。
- 分派记录保留前后负责人、操作人、原因和请求摘要；成功写审计。相同请求重放返回原结果，复用请求身份但更改参数会拒绝；无分派权限的用户不能执行。
- 新建学员默认未分派，客户转学员暂不继承客户负责人；分派不改变既有学校级学员读取范围。这些均是待确认候选规则，不视为负责人已批准。

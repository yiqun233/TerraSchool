# G4 多班入班验证记录

状态：已有有效报名可从教务工作台一次选择多个本校进行中的课程班并原子加入。实现与定向回归已通过，属于候选初版；业务范围、容量/插班和审批规则仍待 Q71/Q60 确认。

## 实现范围

- 新增 `POST /api/teaching/classes/members/batch`，同一事务校验报名有效、教务维护权限、学校一致、目标班级进行中以及每个班级课程出现在报名课程明细中。
- 任一目标不符合条件时整批回滚；没有课程明细的服务费报名不能入课程班。
- 结算模式 0 根据目标班型解析；同一批次若 VIP/普通（含大班）班型无法导出同一解析模式，则拒绝整批。
- 已存在的报名/班级关系作为幂等结果返回，不重复插入或重复写审计。批次最多 20 个目标班，超限拒绝。
- 工作台支持多选本校进行中班级，失败后可以按相同关系重试；默认入班日沿用服务端当前日期。

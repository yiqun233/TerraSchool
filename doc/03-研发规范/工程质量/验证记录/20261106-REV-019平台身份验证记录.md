## 1. 做了什么

### 1.1 数据结构（V81）

`platform` schema 四张表，与租户的 `identity.*` 完全分开：

| 表 | 用途 | 关键约束 |
| --- | --- | --- |
| `platform.operator` | 平台账号 | `login` 全局唯一；与租户账号不共用 |
| `platform.operator_permission` | 平台动作目录 | 取值与租户权限目录不同；`DENY` 预留 |
| `platform.operator_session` | 平台会话 | 只存 token 的 SHA-256，库泄露不等于可登录 |
| `platform.audit_event` | 平台审计 | 独立表，不写 `audit.*`（那是租户可查的审计） |

`ts_platform` 角色：`platform` schema 的读写 + `identity.tenant` 只读 + `identity` schema 的 USAGE。
**没有任何 teaching / enrollment / funds / archive 授权**——「平台不看租户业务数据」由 PostgreSQL 保证。

### 1.2 应用层

| 类 | 职责 |
| --- | --- |
| `PlatformIdentity` | 账号校验、会话签发与解析、动作目录读取、平台审计 |
| `PlatformSessionFilter` | 只认 `TS_PLATFORM_SESSION` Cookie，设置 `ROLE_PLATFORM` |
| `PlatformSecurity` | 独立的 `SecurityFilterChain`（`@Order(1)`，匹配 `/api/platform/**`），独立 CSRF Cookie/请求头，无状态 |
| `PlatformHttp` | `csrf` / `login` / `logout` / `me` 四个入口 |
| `DataSources.platformDataSource` | 以 `ts_platform` 连接的独立连接池 |

配套改动：`verify.py`、升级演练、本地启动脚本、compose 初始化、两份 CI 都增加了 `ts_platform` 角色；
`deploy/docker-compose.yml` 与 `.env.example` 增加平台数据源口令；新增
`tools/ops/bootstrap_operator.py` 用于初始化第一个平台账号（打印一次初始密码）。

## 2. 验证

### 2.1 定向：`PlatformIdentityTest`（6 项，全部通过）

| 用例 | 证明的事 |
| --- | --- |
| `operatorLogsInAndSeesOwnActions` | 平台登录成功，Cookie 带 `HttpOnly`，`me` 返回登录名与动作目录 |
| `wrongOrUnknownCredentialsLookTheSame` | 口令错误与账号不存在都返回同一个 401 码，不泄露账号是否存在 |
| `platformSessionCannotReachTenantEndpoints` | 平台会话访问 `/api/session/me`、`/api/organization/units` 均 401 |
| `tenantSessionCannotReachPlatformEndpoints` | 租户会话访问 `/api/platform/session/me` 401 |
| `expiredSessionIsRejected` | 过期会话即便 Cookie 仍在也 401 |
| `platformRoleCannotReadBusinessTables` | 用 `ts_platform` 直连数据库读 `teaching.class` 被拒（SQLState 42501），读 `identity.tenant` 成功 |

最后一条是关键：它证明隔离不是靠应用层判断，而是数据库层面的权限。

## 5. 限制

- 容器内未验证：本批只在本机临时库上跑过，`deploy_smoke.py` 尚未覆盖平台入口。
- 平台会话 Cookie 的 `Secure` 跟随 `server.servlet.session.cookie.secure`；本机测试为 false，
  生产必须为 true。
- CSRF 用独立的 `XSRF-PLATFORM` Cookie 与 `X-XSRF-PLATFORM` 请求头，与租户链不共用；
  页面实现时需要先取 `/api/platform/session/csrf` 再提交。
- 未做密码强度校验与账号锁定：`bootstrap_operator.py` 只限制长度，登录失败也没有次数限制
  （REV-015 的限流项仍开放）。

## 1. 适用范围与目标

适用于两个内部管理端：**平台运营端**（`/platform`）与**租户管理端**。面向日常高频操作，不是营销页面。

目标只有四条，按优先级排列：

1. **看得懂**：进入页面 3 秒内能回答“我在哪、这页干什么、我现在能做什么”；
2. **不误导**：加载、空、错误、无权限四种状态必须可区分，不能拿空数据冒充；
3. **少出错**：危险动作有确认与后果说明，表单错误就地提示；
4. **可完成**：任何操作都有明确的成功/失败反馈和下一步。

视觉判断标准是“安静的台账”：层级靠间距、留白和字号建立，不靠颜色、阴影和装饰。可信来自一致，
不来自好看。

## 2. 设计原则

| 原则 | 具体含义 |
| --- | --- |
| 骨架固定 | 布局、密度、圆角、字体由平台锁定，租户只换品牌点缀 |
| 一处定义 | 状态色、字号、间距只在主题令牌里定义，页面不写字面值 |
| 数字优先 | 金额、课时、数量用等宽数字右对齐，便于竖排比对 |
| 主操作唯一 | 每页只有一个主按钮，其余为默认按钮或行内链接 |
| 少即是快 | 不引入动画、渐变、重阴影；交互反馈用最短路径 |

## 3. 视觉基线

### 3.1 颜色

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--ts-bg` | `#f7f8fa` | 页面底色 |
| `--ts-surface` | `#ffffff` | 卡片、侧栏、顶栏 |
| `--ts-line` | `#e5e7eb` | 分隔线、卡片描边 |
| `--ts-line-2` | `#f0f1f3` | 表格行分隔 |
| `--ts-line-3` | `#d5d9e0` | 输入框、次要按钮描边 |
| `--ts-ink` | `#1f2937` | 正文与标题 |
| `--ts-ink-2` | `#475467` | 次要文字、表格正文 |
| `--ts-ink-3` | `#6b7280` | 辅助说明、表头 |
| `--ts-ink-4` | `#9ca3af` | 占位符、极弱信息 |

语义色固定，不随租户品牌变化：

| 语义 | 文字 | 背景 |
| --- | --- | --- |
| 成功/正常 | `#067647` | `#ecfdf3` |
| 警告/课时不足 | `#b54708` | `#fffaeb` |
| 危险/欠费 | `#b42318` | `#fef3f2` |
| 进行中/试用 | `#175cd3` | `#eff8ff` |
| 中性/停用 | `#475467` | `#f2f4f7` |

品牌色只通过 `--ts-brand` 系列变量引入，取值与使用范围见[多租户品牌主题方案](../02-架构设计/品牌主题/多租户品牌主题方案.md)第 3、4 节。
页面与组件里**不得出现十六进制颜色**。

令牌落在两个主题模块：`frontend/src/shared/theme/base.css`（L0 中性色、语义色、字号、间距、圆角）与
`frontend/src/platform/platformTheme.css`（平台固定品牌色）；租户品牌的 `--ts-brand*` 由
`TenantBrandingProvider` 在根元素注入。页面 CSS Modules 只引用变量，不再各自定义色值。

### 3.2 字体与字号

| 层级 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | 20/28 | 600 | 每页一个 |
| 区块标题 | 16/24 | 600 | 卡片内分区 |
| 正文 | 14/22 | 400 | 说明、表单值 |
| 表格 | 13/20 | 400 | 列表内容 |
| 辅助 | 12/18 | 400 | 表头、提示、错误 |

- 中文字体使用系统字体栈（PingFang SC / Microsoft YaHei / Noto Sans SC），不引入 Web 字体；
- 数字（金额、课时、数量、日期）加 `font-variant-numeric: tabular-nums`；
- 不靠加粗堆层级，标题与正文的差异主要靠字号和留白。

### 3.3 间距

五档：4 / 8 / 12 / 16 / 24。

| 位置 | 值 |
| --- | --- |
| 页面外边距 | 24 |
| 区块之间 | 16 |
| 卡片内边距 | 16 |
| 表单行间距 | 18（同列）/ 20（跨列） |
| 行内元素 | 8 |

### 3.4 圆角、描边与阴影

- 控件圆角 6，卡片与容器圆角 8；
- 描边统一 1px，不用双线、不用发光边框；
- 阴影只允许出现在浮层（下拉、弹层、抽屉），`0 4px 12px rgba(16,24,40,.08)`；页面与卡片不用阴影。

### 3.5 图标

沿用组件库图标集，不手工绘制业务图标，不混用第二套图标库。状态标签使用“圆点 + 文字”，不依赖图标表意。

## 4. 页面骨架

### 4.1 通用结构

```text
标题（做了什么）          ← 20/600，每页唯一
说明文字                  ← 13，规则、范围、限制，不超过两行
操作区                    ← 主按钮在右，次操作在左
内容区                    ← 表格 / 表单 / 卡片
```

- 标题必须能独立表达“这页做什么”，不用“管理”“列表”这类空词单独成题；
- 说明文字写规则和后果，例如“停用只影响登录，数据保留 90 天”；
- 页面级信息（总数、口径、状态）放在内容区上方，不塞进表格列。

### 4.2 模板 A：列表页

平台端租户列表、租户端学员列表都按这个结构：

1. 标题 + 说明 + 右侧主操作；
2. 数字条：3–4 个关键指标，用 1px 分隔的连续卡片，不用独立浮起的卡片；
3. 内容面板：标签页（带计数）+ 搜索/筛选 + 表格 + 分页。

约束：标签页与筛选同处一行时，标签在左、筛选在右；筛选项不超过 3 个，多出的进“更多筛选”。

### 4.3 模板 B：详情 / 工作台

- 列表进入详情优先用右侧抽屉，保留列表上下文，不做整页跳转；
- 抽屉内部顺序固定：摘要 → 关键字段 → 明细 → 操作；
- 抽屉宽度 480 / 640 / 800 三档，超过 800 改为整页；
- 需要并排比较的场景（如排课、对账）才用整页工作台。

### 4.4 模板 C：向导 / 表单页

- 步骤条在最上方，步骤数不超过 3；
- 表单分区块，每区一个标题，字段两列排布，长文本跨两列；
- 右侧放“须知”卡片，写清一次性凭据、生效时间、不可逆后果；
- 底部操作条固定：左说明、右“取消/下一步”。

### 4.5 导航与顶栏

- 侧栏宽 212，白底，一级项 34 高，分组用 11px 灰色小标题；
- 当前项：浅色底 + 品牌色文字 + 左侧 2px 指示条；
- 顶栏高 52：左侧面包屑，右侧环境标识、帮助、通知、AI 助手与账号；
  未实现入口以“即将开放”或禁用按钮呈现，不留死链；
- 导航按“日常 / 招生 / 教务 / 管理 / 财务 / 设置”分组；平台端按“运营 / 治理”分组，
  未实现项只在配置中保留，运行时标明“即将开放”；
- 租户端侧栏顶部显示租户 Logo 与系统名，平台端显示平台标识；两者不共用同一份配置；
- 当前学校/校区范围尚未做全站切换，顶栏先不放切换器，避免部分页面迁移后出现范围错配。

### 4.6 页面组件落地

租户端与平台端共用同一组页面骨架，组件在 `frontend/src/shared/ui/Page.tsx`：

| 组件 | 用途 | 约束 |
| --- | --- | --- |
| `PageHeader` | 标题、说明、右侧操作 | 每页一个标题；主按钮在右；说明不超过两行 |
| `StatStrip` | 3–4 个关键指标 | 连续卡片、1px 分隔；数字用等宽数字 |
| `Panel` | 表格/内容面板 | 头部放标签页与筛选；底部放总数与分页 |
| `StatusTag` | 状态标签 | 圆点 + 文字；语义色不跟随品牌 |
| `StateBlock` | 空、错误、无权限 | 写清原因与下一步，不冒充空数据 |
| `PageState` | 页面级加载/权限/无范围 | 保留页面标题与说明，避免只剩一句 Alert |
| `TableFooter` | 有总数时分页 | 左侧总数，右侧页码；无总数时用 `SimplePager` |

页面只组合这些组件；新增页面不得再复制侧栏、顶栏、登录或页头结构。

## 5. 表格

| 项 | 约定 |
| --- | --- |
| 字号 | 表头 12、内容 13 |
| 行高 | 列表页 44；抽屉/弹窗内 36 |
| 表头 | 背景 `#fafbfc`，文字 `--ts-ink-3`，不用大写字距 |
| 分隔 | 行间 1px `--ts-line-2`，不画竖线 |
| 悬停 | 整行底色 `#f9fafb` |
| 斑马纹 | 不用 |
| 对齐 | 金额、数量、日期右对齐；文本左对齐 |
| 行操作 | 最多 2 个文字链接，其余进“更多” |
| 分页 | 底部左侧总数，右侧页码；超过 10 页用省略号 |
| 排序 | 有排序的列在表头给明确标识，不给“猜”的机会 |

主标识列（机构、学员）可用两行：名称 + 次级信息（城市、学员号），其余列保持单行。

## 6. 四种状态

| 状态 | 要求 | 反例 |
| --- | --- | --- |
| 加载中 | 表格 `loading`，局部用骨架；不显示“0 条” | 加载时显示空表 |
| 空 | 说明为什么空 + 下一步动作 | 只写“暂无数据” |
| 错误 | 可读原因 + 重试入口，不暴露堆栈与状态码 | 只弹“操作失败” |
| 无权限 | 说明缺什么权限、找谁开通 | 直接不显示，用户以为没数据 |

空态分四种，文案不能混用：

1. 还没有数据：“还没有租户，开通第一家机构”；
2. 筛选无结果：“没有符合条件的租户，试试清空筛选”；
3. 无权限：“需要 `TENANT_READ` 权限，联系平台管理员开通”；
4. 未开通功能：“该功能将在开通后可用”。

## 7. 表单

- 标签在上方，13px、500，必填用红色星号，不用占位符承载标签；
- 输入框高 32（页面内）/ 34（向导），错误时红框 + 12px 红色说明；
- 就地校验：失焦即提示，不等提交；错误信息给“怎么办”，例如“编码已被使用，可改用 YF-0107”；
- 提交中按钮 `loading` 并禁用重复提交；
- 失败保留已填内容，焦点回到出错字段；
- 网络结果不确定时提示“用相同内容重试”，不自动重放写请求；
- 字段说明写在控件下方，不用 tooltip 承载规则。

## 8. 反馈与危险操作

| 场景 | 做法 |
| --- | --- |
| 普通成功 | 顶部轻提示，2 秒消失，不打断 |
| 危险操作 | 二次确认，写清后果与范围，例如“停用后该机构所有人无法登录，数据保留 90 天” |
| 不可逆操作 | 需要输入对象名称确认，按钮用危险色 |
| 长任务 | 给出进度或“已提交，可在开通记录查看” |
| 一次性凭据 | 只展示一次，提供复制，明确“离开后无法再次查看” |

主按钮在确认框中放在右侧，默认焦点在“取消”，避免回车误触。

## 9. 文案与术语

- 动词开头：“开通租户”“重置密码”“停用账号”；
- 错误文案三段式：发生了什么 + 为什么 + 怎么办；
- 不写内部术语与英文状态码，必须出现时同时给中文；
- 同一动作全站同一叫法。

| 统一用法 | 不用 |
| --- | --- |
| 租户 / 机构 | 客户、学校（在平台语境下） |
| 学员 | 学生（除家长语境） |
| 剩余课时 | 余额、课时数 |
| 停用 / 恢复 | 禁用、冻结、删除 |
| 开通 | 创建、注册（租户语境） |

## 10. 多租户约束

- 品牌色只出现在[方案第 3.1 节](../02-架构设计/品牌主题/多租户品牌主题方案.md)允许的位置；
- 状态色、错误色、危险按钮永不跟随品牌色；租户换成橙色时，“课时不足”仍必须是琥珀色；
- 状态标签必须“圆点 + 文字”，禁止只靠底色区分；
- 平台端使用固定主题，不读取租户配置；租户端不显示平台运营的标识；
- Logo 有安全区，不裁切、不拉伸、不与文字重叠；侧栏放不下时退化为方形图标。

## 11. 可访问性与可测试性

- 所有输入有可访问名称（`aria-label` 或关联 `<label>`），也是测试查询依据；
- 键盘可完成主路径，焦点样式不被移除，焦点环对比度 ≥ 3:1；
- 正文对比度 ≥ 4.5:1，大字号 ≥ 3:1；
- 弹窗打开后焦点进入弹窗，关闭后回到触发元素；
- 表格与列表提供稳定的可查询标识，避免测试依赖位置。

## 12. 交付门禁

新页面或改版合并前必须通过：

1. 标题与说明齐全，3 秒能说清页面用途；
2. 四态可见（可用构造数据或开关）；
3. 主路径有成功/失败反馈，失败可重试且不丢输入；
4. 危险动作有确认且写明后果；
5. 全键盘走查一次主路径；
6. 与相邻页面在标题层级、间距、按钮位置上一致；
7. 自动检查：TypeScript、ESLint、Prettier、组件测试通过；主题模块之外无十六进制颜色；
8. 租户端改动额外检查：换色后按钮、链接、选中行、焦点环仍达标。

走查由负责人按真实业务任务执行，结论记入对应验证记录。

## 13. 迁移节奏

- 第一批：平台运营端的租户列表、开通向导、租户详情与停用/恢复（REV-020 剩余与 REV-021）；
- 第二批：租户端高频页（学员、排课、收款与退款），此后新页面直接按本规范做；
- 已有页面按批次套用，不做一次性重写；未迁移页面在改动时顺带补齐，不新造样式；
- 2026-11-08 已完成：平台端缺陷修复与壳层补齐；租户端登录、强制改密、分组导航与顶栏；
  组织目录、学员档案、招生渠道、本人客户、课程与产品、报名与收款、教务与考勤、审批、
  财务期间、数据迁移、统一字典、员工/教师/教室、品牌设置均已接入新壳与页头。
- 品牌主题能力（换色、Logo）随平台端交付后，在租户端设置页开放；当前已开放预设换色与显示名，
  Logo 上传待文件存储接入后开放。
